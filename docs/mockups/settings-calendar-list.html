Day, Week and Month switch at the top; Day is the same grid for one day, wider, with the event's details alongside. Working hours are shaded lighter (9 to 5, Monday to Friday, set in Notifications & Reminders), a red line marks now, and it scrolls to the current time. Options next to Week starts on: Show week numbers, Hide weekends, Working hours. Click an event for the same preview with Join as now. Making and moving events stays in Google or Outlook for now.
