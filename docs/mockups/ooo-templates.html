Out of Office templates

These work like Lightroom presets. Set up Out of Office the way you want it, then Save as new template. You pick which parts the template keeps. Applying a template later only changes those parts and leaves the rest alone. The four built-in templates (Away, Holiday, Conference, Off sick) stay as they are.

Each tick shows what's set now, so you can see exactly what will be saved.

Dates: a template never stores a fixed date such as 14 Nov. "Between dates" is saved as the days and times it covers ("Friday 13:00 to the end of Friday", or "2 weeks from the next Monday"). Applying it fills in the next matching dates, which you can still change.

If a template with that name already exists, the button changes to Replace template.
