Calendar Groups

A group such as Work or Personal collects calendars from any account. Picking a group shows only its calendars. "All" shows everything you haven't hidden, which is how it works today.

This is the same list as the Calendars menu, grouped under each account with its colour. A calendar can be in more than one group.

New event uses the group too. While Work is showing, new events go to the first calendar in Work, and the Calendar list in the form shows that group's calendars first.

Groups are also set up in Settings › Calendar & Reminders, on a Calendar Groups card with New group, and Edit on each row.

3 · Alerts while a group is showing
Only alert me from the group I'm looking at
Off: you get alerts from every shown calendar, whichever group is picked.

Off by default, so switching to Personal at the weekend never quietly hides a work meeting. With it on, picking Personal works as a "weekend mode".
